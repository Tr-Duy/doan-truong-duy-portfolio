# Đoàn Trường Duy - Java Backend Developer Portfolio

A professional, modern, responsive personal portfolio website built for **Đoàn Trường Duy**, specializing in Java Backend Development (Java 21, Spring Boot 4, Spring Security, RESTful APIs, MySQL).

## Tech Stack

- **Framework**: React 19
- **Language**: TypeScript
- **Build Tool**: Vite
- **Styling**: Tailwind CSS v4
- **Icons**: Lucide React
- **Linter**: ESLint

## Features

- **Java Backend Focus**: Specially tailored for recruiters, HR, and technical engineering managers looking for Java Backend Intern / Fresher candidates.
- **Dark / Light Theme Toggle**: Persistent theme state with `localStorage` and system default detection.
- **Experience Timeline**: Highlights metrics (**90+ APIs**, **17 JPA Entities**, **16 Controllers**, **4 User Roles**, **70+ Secured Methods**, **86 Tests**).
- **Featured Projects Showcase**:
  - Primary Project: **English Vocabulary Learning System (SRS)** with **170+ API Mappings**, **34 JPA Entities**, **65 Test Classes**, **295+ JUnit Tests**, **30 Flyway Migrations**, and a technical architecture deep-dive modal.
  - Secondary Project: **C++ Data Structures & Algorithms** repository.
- **Grouped Skills**: Highlighting Java, Spring Boot, Spring Security, MySQL, JUnit 5, and Docker.
- **Education & Awards**: STU Bachelor of IT entry (GPA 3.1/4.0) with STU research and startup competition awards.
- **Certifications**: YoEdu Academy and Rikkei Education credentials.
- **Direct CV Download**: Direct access to `/CV-Doan-Truong-Duy.pdf`.
- **Contact & Action CTAs**: Direct `mailto:`, `tel:`, and copy-to-clipboard functionality.

## Development

```bash
# Install dependencies
npm install

# Start local development server
npm run dev
```

## Build & Quality Check

```bash
# Run ESLint linter
npm run lint

# Compile TypeScript & Build production bundle
npm run build
```

## Deployment

Configured for **Vercel** deployment with Vite framework defaults.
- Build Command: `npm run build`
- Output Directory: `dist`
